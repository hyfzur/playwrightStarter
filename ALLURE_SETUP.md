# Allure setup for Playwright

This project includes Allure reporting support for Playwright test runs.

## Setup

Install dependencies:

```bash
npm install
```

Install Playwright browsers if necessary:

```bash
npx playwright install
```

## Commands

Run tests with Allure output:

```bash
npm run test:allure
```

Generate and open the HTML Allure report:

```bash
npm run allure:report
```

## Output folders

- `allure-results/` stores raw Allure data generated by Playwright.
- `allure-report/` stores the generated HTML report.

## Notes

The project continues to keep the standard Playwright HTML report enabled alongside Allure output.
